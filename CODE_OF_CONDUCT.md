# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and make the project welcoming for people of every background and experience level. Harassment of any kind is not tolerated.

To report unacceptable behaviour, contact the maintainer privately through the repository's **Security** tab (**Report a vulnerability**) or the contact on their GitHub profile. Reports are handled confidentially.
